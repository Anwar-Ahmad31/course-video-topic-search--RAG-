# 🎓 RAG — Python Tutorial Video Q&A Engine

A **Retrieval-Augmented Generation (RAG)** system that lets you ask questions about a 100-day Python programming video course and get accurate, source-cited answers powered by a local LLM.

---

## 📌 What It Does

- 🎙️ **Transcribes** video audio (Hindi → English) using [OpenAI Whisper](https://github.com/openai/whisper)
- 🔢 **Embeds** transcript chunks using [`bge-m3`](https://ollama.com/library/bge-m3) via [Ollama](https://ollama.com)
- 🔍 **Retrieves** the most relevant chunks using cosine similarity
- 🤖 **Generates** answers with a local LLM (`llama3.2:3b`) — no internet needed after setup


## ⚙️ Prerequisites

### 1. Python (3.9+)
Install dependencies:
```bash
pip install -r requirements.txt
```

### 2. Ollama
Download from [https://ollama.com](https://ollama.com) and install it.  
Then pull the required models:
```bash
ollama pull bge-m3        # embedding model
ollama pull llama3.2:3b   # LLM for answer generation
```
Make sure Ollama is **running** before executing the notebooks:
```bash
ollama serve
```

### 3. FFmpeg (for audio extraction from video, if needed)
Download from [https://ffmpeg.org](https://ffmpeg.org) and add it to your system PATH.

## 🚀 How to Run (Step by Step)

### Step 1 — Transcribe Audios (`chunks.ipynb`)
- Place your `.mp3` audio files inside the `audios/` folder.
- File naming format must be: `001_Title of the video.mp3`
- Run all cells → generates `jsons/` (raw) and `main_jsons/` (merged chunks)

### Step 2 — Generate Embeddings (`read_chunks.ipynb`)
- Make sure Ollama is running with `bge-m3` pulled.
- Run all cells → generates `main_embedded_jsons/` (chunks + 1024-dim vectors)

### Step 3 — Test Retrieval (`main_cosine_similarity.ipynb`) *(optional)*
- Run to verify that cosine similarity search is returning relevant chunks.

### Step 4 — Ask Questions (`rag_engine.ipynb`)
- Make sure Ollama is running with both `bge-m3` and `llama3.2:3b` pulled.
- Run Cell 0 to load the corpus.
- Run Cell 1 — enter any question and get a streamed answer with sources!

## 🔧 Configuration

Each notebook has a **Configuration** section at the top. Key settings:

| Setting | Default | Description |
|---|---|---|
| `MODEL_NAME` | `"base"` | Whisper model size (`tiny`, `base`, `small`, `medium`, `large`) |
| `GROUP_SIZE` | `5` | Number of Whisper segments merged into one chunk |
| `EMBEDDING_MODEL` | `"bge-m3"` | Ollama embedding model |
| `LLM_MODEL` | `"llama3.2:3b"` | Ollama LLM for generation |
| `LLM_USE_GPU` | `True` | Set `False` if you don't have a GPU |
| `TOP_K` | `4` | Number of top chunks to retrieve |
| `MIN_SCORE` | `0.30` | Minimum cosine similarity threshold |
| `NEIGHBOR_WINDOW` | `0` | Extra context chunks around each hit (0 = none) |
| `SHOW_SOURCES` | `True` | Print source citations after each answer |

## 📝 Notes

- All inference is **100% local** — no API keys or internet required after model download.
- The system supports **multi-topic questions** — it automatically splits compound questions and retrieves context for each sub-topic separately.
- Whisper output may contain **recognition errors** (e.g., names slightly misspelled). The LLM prompt instructs the model to interpret them sensibly.
